# 淘宝数据 Provider 合规接入预研

> 状态：**blocked**
> 更新日期：2026-07-16
> 适用范围：T07 技术 Spike；本文不构成法律意见或平台授权证明。

## 结论

截至本次预研，尚未取得可验证的正式书面授权、应用资质、接口权限清单和数据处理条款，无法确认存在同时满足以下需求的生产数据通道：

- 通过用户提交的淘宝商品链接识别商品；
- 获取商品、店铺、SKU、价格和售后等事实；
- 获取可按近 30 天或近 60 天筛选的评论正文及评论时间；
- 允许将评论用于模型分析、短期保存和向终端用户展示聚合结论；
- 允许建立商品或 SKU 粒度的评论关联。

因此：

1. **T09 生产淘宝 Provider 暂停实施。**
2. **真实淘宝分析不得发布到生产环境。**
3. M0、M1、M2 可继续使用合成 `FixtureCommerceDataProvider` 做内部开发、自动化测试和演示。
4. URL 白名单与 SSRF 防护只解决网络安全问题，不代表获得淘宝数据访问或使用授权。

## 已核查入口

- 淘宝开放平台主页：<https://open.taobao.com/>
- 淘宝规则平台：<https://rulechannel.taobao.com/>
- 阿里巴巴法律与隐私条款入口：<https://terms.alicdn.com/>

公开入口本身不能证明本项目已拥有具体接口权限。进入 T09 前，必须由实际应用主体登录开放平台并取得应用审批、接口权限、合同/条款确认和可留存的审批证据。

## 生产放行前置条件

必须逐项取得证据：

- [ ] 明确的数据提供主体和正式授权渠道；
- [ ] 应用创建、审核和调用凭据已批准；
- [ ] 商品、SKU、店铺、售后和评论接口名称及版本已确认；
- [ ] 评论正文、评论时间和 SKU 关联字段的可用性已确认；
- [ ] 近 30/60 天筛选、排序和分页语义已确认；
- [ ] 调用频率、配额、SLA、费用和停服策略已确认；
- [ ] 数据存储、模型分析、派生统计、终端展示和删除规则已书面确认；
- [ ] 评论中的个人信息处理、脱敏和保留期限已通过合规评审；
- [ ] 凭据只进入 Secret Manager 或环境变量，不进入代码、日志、数据库和 Prompt；
- [ ] 合规、法务或平台责任人给出书面放行结论。

## 明确禁止的替代方案

本项目不设计、不实现也不接受以下生产方案：

- 绕过登录、验证码、访问控制、反爬或平台风控；
- 使用代理池、浏览器指纹伪装或隐蔽自动化采集；
- 要求用户提供淘宝 Cookie、账号、Token 或登录态；
- 把 Cookie、Authorization、完整页面或凭据写入 Prompt、日志、数据库或 Fixture；
- 将未授权页面抓取包装成“开放 API”或“公开数据”；
- 在未确认权利前复制真实评论到测试目录或金标集。

## 候选接入路径评估

| 路径 | 状态 | 生产可用结论 | 需要补充的证据 |
|---|---|---|---|
| 淘宝开放平台正式 API | 待应用主体核验 | blocked | 应用审批、具体 API 权限、字段、评论使用条款、配额 |
| 具备淘宝书面许可的第三方数据服务 | 尚无供应商与合同 | blocked | 上游授权链、数据来源、再授权范围、SLA、隐私与保留条款 |
| 商家自有数据导入 | 产品范围尚未定义 | conditional | 用户身份、数据所有权、导入格式、授权声明、SKU 口径 |
| 页面抓取或浏览器自动化 | 禁止 | rejected | 不进入评估 |

## 下一次复审输入

只有获得以下材料后才复审：正式 API 文档快照、应用权限截图或审批记录、数据处理条款、字段样例（必须脱敏）、配额与计费说明、法务/合规结论。复审后将状态更新为 `approved`、`conditional`、`blocked` 或 `rejected`，并同步更新字段矩阵。
